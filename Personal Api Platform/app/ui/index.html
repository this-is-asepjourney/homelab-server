💡 Panduan Menggunakan Local DNS di Perangkat Klien

Opsi A: Setting DNS di Router / Wi-Fi (Semua HP & Laptop)

  1. Buka pengaturan DHCP / DNS pada Router Wi-Fi Anda.
  2. Ubah Primary DNS Server ke IP: 192.168.25.101.
  3. Isi Secondary DNS Server ke: 1.1.1.1.
  4. Selesai! Semua perangkat di rumah langsung bisa buka http://*.homelab.

Opsi B: Menggunakan File Hosts (Tanpa Ubah Router)

  1. Klik tombol Unduh hosts.txt di atas.
  2. Windows: Salin isi file ke C:\Windows\System32\drivers\etc\hosts
  3. Linux / Mac: Tambahkan ke /etc/hosts
  4. Browser Anda langsung bisa membuka http://psm.homelab dll.
